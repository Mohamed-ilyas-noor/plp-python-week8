
# My Personal Mini-Toolkit

## Project Description

My Personal Mini-Toolkit is a Python application that combines four useful tools into one menu-driven program.

Users can select different tools from the main menu and return to the menu whenever they finish.

## Tools Included

### 1. Simple Calculator
Performs addition, subtraction, multiplication, and division.

### 2. Number Guessing Game
Allows users to guess a random number between 1 and 10.

### 3. To-Do List Manager
Allows users to add, view, and remove tasks.

### 4. Name Formatter
Displays names in uppercase, lowercase, and title case.

## How to Run the Program

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run this command:

```bash
python toolkit.py
```

6. Select a tool by entering its number.
7. Select option 5 to quit.

## Reflection

The hardest part of this project was creating the menu loop and making sure all the tools returned to the main menu correctly. The bug that took the longest to fix was handling invalid user input without crashing the program. I solved this problem by using if statements and try-except blocks. I learned how to use lists to store and manage tasks while the program was running. I also improved my understanding of loops, functions, and conditional statements. The project helped me become more confident in writing Python programs. If I had one more week, I would add a currency converter and a feature that saves tasks permanently in a file.
